# S0 — Walking skeleton: package, --version, test runner

## Goal
Create the importable `todo` package, a `python -m todo` entry point with `--version`,
the CLI dispatch module that later slices plug into, and a test tree that both
`python -m unittest discover -s tests -t .` and `python -m unittest discover -s tests` run green.

## Interface
Files (repo root):
- `todo/__init__.py` — defines `__version__ = "0.1.0"` (string, PEP 440).
- `todo/__main__.py` — only: `import sys; from todo.cli import main; sys.exit(main())`.
- `todo/cli.py` — `main(argv: list[str] | None = None) -> int`. Builds an `argparse.ArgumentParser(prog="todo")`
  with `--version` (action="version", text `todo <__version__>`) and a subparsers object
  (`dest="command"`). It also defines `COMMAND_MODULES: list[str] = []` and, in `main`, imports each
  dotted name and calls its `register(subparsers)`; if a parsed command has `func`, return `args.func(args)`.
  S0 ships the empty list; S2/S4/S5 each append one entry (full rule in the S2 contract).
  `main` never calls `sys.exit` itself for normal returns; argparse's own exits (`--version`, usage errors) are fine.
- `tests/__init__.py`, `tests/acceptance/__init__.py` (empty) — required so discovery with `-t .` imports
  `tests.acceptance.s0` etc. Every `tests/acceptance/<sliceid>/` dir also needs an `__init__.py` (QA creates its own).
- `tests/test_smoke.py` (dev-owned) — imports `todo`, asserts `__version__` is a non-empty str.

Examples:
- `python -m todo --version` -> stdout `todo 0.1.0\n`, exit 0
- `python -m todo` (no args) -> usage text on stderr, exit 2 (non-zero)
- `python -c "import todo; print(todo.__version__)"` -> `0.1.0`

## Acceptance
1. From repo root, `python -m todo --version` exits 0 and stdout (stripped) equals `"todo " + todo.__version__`.
2. `todo.__version__` is a str matching `^\d+\.\d+\.\d+$`.
3. `python -m todo` with no arguments exits non-zero (2) and writes something containing `usage` to stderr; stdout is empty.
4. `python -m todo --bogus` exits 2 with `usage` on stderr.
5. `from todo.cli import main; main(["--version"])` raises `SystemExit` with code 0 (argparse behaviour) — i.e. `main` accepts an argv list and does not read `sys.argv` when one is given.
6. `python -m unittest discover -s tests -t .` exits 0 and runs >= 1 test.
7. `python -m unittest discover -s tests` (brief's form, no `-t`) also exits 0.
8. `tests/__init__.py`, `tests/acceptance/__init__.py`, `todo/__init__.py`, `todo/__main__.py`, `todo/cli.py` exist.
9. No non-stdlib imports anywhere under `todo/` (grep for imports; all resolve with a bare Python 3 install).
Preservation: none (first slice).

## Out of scope
Any task commands, store, REST, CSV. Packaging (setup.py/pyproject) is not required.
